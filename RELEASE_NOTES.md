# Telinha release notes
## Features

None.

## Improvements

1. The message box grows with what is written up to 200 px and then scrolls, with the scroll bar in sight.
2. A message longer than 2000 characters is sent whole as the file mensagem.txt instead of being cut, and the box says so before sending.

## Fixes

1. Deafening in a call did not silence the microphone. Now, as in Discord, it does, and hearing again brings the microphone back as it was.
2. Long pasted text ran past the bottom of the message box and could not be seen.
